# For You ❤️ — Romantic Apology Website

A soft, interactive, mobile-friendly apology page. Send the link, they open it, hearts happen.

## Personalize it (no coding)

Open **`config.js`** and edit the text between the quotes:

- `hero` — first screen heading, message, button
- `apology` — the long personal message (types out on screen)
- `gift` — gift box title + hidden message
- `reasons.cards` — the 5 reason cards (emoji, title, text)
- `talk` — the two response buttons and their replies
- `final` — closing message + button
- `song` — YouTube video id / title (if you ever want a different song)

Save the file and push — GitHub Pages updates the live site in about a minute.

## Live site

Deployed with GitHub Pages from the `main` branch (root).

## Privacy

Fully client-side. No accounts, no tracking, no analytics. The visitor's button choices are never sent anywhere.
